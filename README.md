# PhoneOBS

PhoneOBS is a GitHub Pages dashboard that creates VDO.Ninja links for up to four phone cameras.

## Static GitHub Pages mode

The dashboard uses VDO.Ninja for camera transport, signaling, and relay support. Open the published page, open a camera link on the phone, then paste the matching viewer link into an OBS Browser Source.

The GitHub Pages workflow publishes `server/public` automatically. No local Node server, Supabase project, native OBS plugin, CMake, or Visual Studio tools are required.
